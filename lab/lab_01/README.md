# Лабораторная работа №1

## Задание 1. Используя файл dictionary.txt, выполните приведенные ниже подзадачи. Решением каждой подзадачи является одна содержащая последовательный набор команд строка, выполняемая в CLI.

### 1. Подсчитайте количество всех слов в словаре. Вывод вашей команды должен содержать только количество слов.

```bash
wc -w < dictionary.txt
```

### 2. Найдите число слов, которые содержат ровно 3 буквы o без учета их регистра.

```bash
grep -icE '^([^o]*o){3}[^o]*$' dictionary.txt
```

### 3. Найдите число слов, которые содержат ровно 3 буквы o, отделенные друг от друга хотя бы одним другим символом.

```bash
grep -icE '^[^o]*o[^o]+o[^o]+o[^o]*$' dictionary.txt

```

### 4. Среди наборов из первых трех букв в словах, которые содержат смежные “o” выведите в лексикографическом порядке 3 набора из первых трех букв, которые встречаются наиболее часто.

```bash
grep 'oo' dictionary.txt | cut -c1-3 | sort | uniq -c | sort -rn | head -n 3 | sort | awk '{print $2}'
```
