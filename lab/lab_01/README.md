# Лабораторная работа №1

## Задание 1. Используя файл dictionary.txt, выполните приведенные ниже подзадачи. Решением каждой подзадачи является одна содержащая последовательный набор команд строка, выполняемая в CLI.

### 0. Предобработка

```bash
tr -s '[:space:]' '\n' < dictionary.txt
```

### 1. Подсчитайте количество всех слов в словаре. Вывод вашей команды должен содержать только количество слов.

```bash
wc -w < dictionary.txt
```

### 2. Найдите число слов, которые содержат ровно 2 буквы ‘с’ без учета их регистра.

```bash
grep -icE '^([^c]*c){2}[^c]*$' dictionary.txt
```

### 3. Найдите число слов, которые содержат ровно 2 буквы ‘t’, отделенные друг от друга хотя бы одним другим символом.

```bash
grep -icE '^[^t]*t[^t]+t[^t]*$' dictionary.txt
```

### 4. Определите первые 3 упорядоченных набора из 3-х первых букв, которые наиболее часто встречаются для слов, которые не содержат смежные ‘o’

```bash
grep -v 'oo' dictionary.txt | cut -c1-3 | sort | uniq -c | sort -rn | head -n 4 | sort | awk '{print $2}'
```

### 1. Создание пустой директории с именем data_analysis. Убедитесь, что ваш скрипт корректно отрабатывает в случае, когда директория с данным именем уже существует.

### 2. Создание файла research_themes внутри директории data_analysis, который содержит все уникальные темы исследований в алфавитном порядке, а последняя строка в данном файле это число всех уникальных направлений исследования.
